# Reporting security issues

Do not publish private evidence or credentials in a public issue. Report an issue
privately to the repository owner through an available private contact or GitHub
private vulnerability reporting when enabled. No contact address or response SLA
is assumed by this project.

Include the affected version, platform, scope, minimal sanitized reproduction and
impact. Preserve original evidence privately. See the [security model](docs/security.md)
for trusted-command, environment, evidence and isolation limitations.
